## Project Overview
This repository contains Part 1 of a three-part Portfolio of Evidence for the WEDE5020 module. The project is a website for **Paws Haven Animal Rescue**, a fictional animal rescue organisation that shelters, medically treats, and rehomes rescued dogs. Part 1 focuses on building the foundation of the website using semantic HTML — structure, content, and navigation — with styling (CSS) and interactivity (JavaScript) to follow in Parts 2 and 3.

## Website Goals / Objectives
- Raise awareness of Paws Haven Animal Rescue and the work it does
- Showcase dogs currently available for adoption
- Make it easy for visitors to volunteer, sponsor a dog, or make an enquiry
- Provide clear contact details and shelter locations
- Build a simple, accessible, and easy-to-navigate site structure

## Key Features / Functionality
- Semantic HTML structure using `header`, `nav`, `main`, `footer` on every page
- Consistent navigation menu across all 5 pages
- Homepage with hero section and an overview of the organisation's work
- About Us page detailing the organisation's story, mission, vision, and team
- Adoption page listing available dogs with photos and adoption process steps
- Volunteer / Sponsor enquiry form
- Contact page with two embedded Google Maps locations and a contact form
- SEO-friendly meta tags (description and keywords) on every page
- Code comments throughout for clarity and maintainability
