Project Overview 
This repository contains Parts 1 and 2 of a three-part Portfolio of Evidence for the WEDE5020 
module. The project is a website for Paws Haven Animal Rescue, a fictional animal rescue 
organization that shelters, medically treats, and rehomes rescued dogs. Part 1 built the foundation 
of the website using semantic HTML  structure, content, and navigation. Part 2 adds CSS styling 
and responsive design, giving the site a cohesive visual identity and ensuring it works well on 
desktop, tablet, and mobile screens. Part 3 (JavaScript interactivity) is still to follow. 
Part 1 Feedback 
Part 1 was marked and returned with a result of 98%, with not much feedback. As there were no 
multiple mistakes to point out, Part 2 proceeded directly with the planned CSS styling and 
responsive design work. 
Website Objectives 
• Raise awareness of Paws Haven Animal Rescue and the work it does 
• Showcase dogs currently available for adoption 
• Make it easy for visitors to volunteer, sponsor a dog, or make an enquiry 
• Provide clear contact details and shelter locations 
• Build a simple, accessible, and easy-to-navigate site structure 
• Present the site with a cohesive, professional visual identity that works across desktop, 
tablet, and mobile devices 
Functionality 
• Semantic HTML structure using header, nav, main, footer on every page 
• Consistent navigation menu across all 5 pages 
• Homepage with hero section and an overview of the organization's work 
• About Us page detailing the organization's story, mission, vision, and team 
• Adoption page listing available dogs with photos and adoption process steps 
• Volunteer / Sponsor enquiry form 
• Contact page with two embedded Google Maps locations and a contact form 
• SEO-friendly meta tags (description and keywords) on every page 
• Code comments throughout for clarity and maintainability 
• External stylesheet (style.css) applying consistent colors, typography, and spacing across 
every page 
• Flexbox and CSS Grid layout for the navigation menu, dog adoption cards, and multi
column content sections 
• Interactive hover, focus, and active states on links, buttons, and form fields 
• Fully responsive design with dedicated breakpoints for tablet and mobile screens

Part 1 Details 
Part 1 covers the foundation of the website: - Two website project proposals (Paws Haven Animal 
Rescue and Sweet Crumb Bakery), with Paws Haven Animal Rescue selected as the chosen 
organisation - Research and sourcing of content used to inform the website’s copy and structure - 
A sitemap outlining the site’s page hierarchy - A file/folder structure separating css, js, and images 
from the HTML files - Five HTML pages: index.html, about.html, services.html, enquiry.html, 
contact.html 
Part 2 Details 
Part 2 covers the visual design and responsiveness of the website: - A single external stylesheet 
(css/style.css) linked to all five HTML pages - A CSS reset and a base style layer using CSS custom 
properties (variables) for colors, spacing, and typography - Typography styling with a consistent 
font scale across headings and body text - Layout structure built with Flexbox (navigation, dog 
adoption cards) and CSS Grid (homepage “What We Do” section, About Us Mission/Vision section) - Decorative and colour styling using a warm, cohesive palette suited to an animal rescue 
organisation - Interactive pseudo-classes (:hover, :focus, :active, :focus-visible) on navigation 
links, buttons, and form fields - Responsive design with two breakpoints (768px for tablet, 480px for 
mobile), adjusting layout, typography, navigation, and images at each breakpoint - A separate Part 
2 documentation report explaining how each rubric requirement was met
